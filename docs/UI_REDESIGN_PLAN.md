## 一、当前设计决策

- Vue 2 Options API，CSS 语义变量 + SCSS 别名，不新增依赖。
- 深色采用蓝灰体系，避免近乎纯黑：页面 #202633、卡片 #29313E、输入/次级块 #303949、hover #3A4556。
- 页面外壳最大宽度 1400px（含左右各 24px 内距），导航同宽；年度报告与视频等专门阅读/媒体布局可使用更窄的内容区。
- 页面标题 28px、详情 hero 32px、模块标题 20px；封面与沉浸式内容允许有明确用途的字号例外。
- 主题入口为太阳/月亮左右开关，显式切换浅色/深色；首次无偏好时仍按系统解析，兼容已有 system 偏好与跨标签同步。持久化键 acmusic_theme，首帧脚本底色须与 token 同步。
- 歌曲列表保留歌名/歌手两行结构，单击歌名播放，原生按钮支持键盘；附加列按整表统一布局，管理操作单独预留。
- 发现/搜索/登录的页面导航使用公共 ac-tabs 下划线样式；用户面板内部的紧凑筛选可保留胶囊。
- 图片叠字恒为反白；按钮前景用独立 token。不能把所有白色或固定色值一律替换。
- 搜索弹层采用独立蓝紫深色语境；播放器及其评论保持独立深色语境，普通页面评论随主题切换。
- 保留系统字体栈，不引入 Barlow。主按钮文字对比度通过配套按钮底色处理。

## 三、当前覆盖的功能与样式

### 主题与基础组件

- tokens.scss 是页面语义色的维护位置；variables.scss 保存别名和不随主题变化的排版尺度。
- theme.js 处理偏好读取/保存/应用、系统变化、跨标签同步与监听清理。存储受限时保留当前会话的手动选择。
- Element 覆盖在 theme-chalk 之后加载；只覆盖实际使用的组件，不以加载文件就视为覆盖全部状态。
- 共享骨架、滚动条、主要按钮、EmptyState 与 LoadMore 接入语义色。
- 搜索弹层输入、建议、热搜和滚动条统一蓝紫色；保留 Enter 搜索、点击联想及 Escape，新增明确关闭按钮。

### 页面与列表

- 首页公开推荐卡、漫游行/心动卡、私人 FM ambient 与外壳接入主题。
- 发现 MV/视频列表补齐首屏/分页失败提示与手动重试，成功后提交偏移，筛选请求版本隔离；视频标签独立重试，MV 跨组同值筛选正常刷新。
- 发现全部/精品歌单补齐分类或标签独立失败、列表首屏失败/空态/分页重试；快速切换隔离旧响应，精品续载保留卡片，分页成功后推进位置。
- 发现五分区、搜索九分类的媒体卡/筛选/用户卡接入主题。搜索空结果与首次失败分开，支持重试；首次加载结束前不挂载自动加载更多。
- 评论首屏区分加载/失败/空态，热门失败独立重试，分页失败不跳页并保留内容；请求版本隔离切歌后的旧响应。LoadMore 支持结束状态恢复后重新观察。
- 普通页评论与楼中楼走 comment-*，删除歌单/专辑/视频三套重复颜色反补丁；评论编辑器修正样式穿透、列宽、发送禁用与回复取消。
- 用户主页关注/粉丝卡、头像墙、操作按钮、筛选、排行/云盘/收藏/歌单/社交空态接入主题。
- 404、年度报告的歌曲/状态/反馈/骨架、歌手详情骨架与子页按钮接入主题。
- 歌单详情新增详情/歌曲独立失败重试、空态和请求版本隔离；修正歌曲 offset 按条数推进，实页验证 50→100→114 首。
- 专辑详情新增参数无效/加载失败重试/歌曲空态与旧响应隔离；歌手全部歌曲/专辑页区分空结果、首次失败和分页失败，重试保留已有内容与 offset。失败恢复目前有离线合成验证，真实断网仍待验收。
- MV 缺少发布日期时隐藏日期，避免过滤器将缺失日期显示为当天。
- MV/视频详情增加详情错误重试与播放源独立重试，相关推荐失败不影响 URL；保留 Mlog/数字 MV 跳转并隔离旧响应。实页验证无参数和真实无源 MV，未声称完整播放或网络故障恢复通过。
- 浏览器 22 项标注已落实：封面 hover/卡片等高、太阳月亮开关、用户页列宽/社交 Tab、歌单播放入口/评论数、未公开文案、Mlog 播放量兼容，以及展开播放器双栏/副歌标注（第二轮按反馈精简设置、音量、队列入口）。逐项结果与验证边界见 CHANGELOG_AI.md。

## 六、Token 速查

| 用途 | 应用的变量 |
| --- | --- |
| 页面/卡片/输入表面 | --c-bg-base / elevated / sunken / sunken-hover |
| 正文/副信息/辅助文字 | --c-text-primary / secondary / tertiary |
| 链接/激活文字 | --c-accent-text |
| 装饰线/选中浅底 | --c-accent / soft / soft-strong |
| 实心主按钮 | --c-button-primary / primary-hover + --c-text-on-accent |
| 图片上的白字 | --c-text-inverse |
| 描边/阴影 | --c-border / strong；--c-shadow-low / mid / high |
| 成功文字/浅底 | --c-success-text / soft（反馈语义）；装饰绿仍独立 |
| 评论 | --comment-*；playerWrapper 局部覆写 |
| 搜索弹层 | --search-*（独立蓝紫深色） |
| 骨架/玻璃/FM | --c-shimmer-start / mid；--c-glass；--c-fm-ambient |
| 排版/间距/圆角 | variables.scss 的 $fs-* / $sp-* / $radius-* |
| 动画 | motion.scss 的时长/缓动/卡片 token |

$color-main 已接入运行时 CSS 变量；主色的 Sass rgba/lighten/darken 调用已迁移。透明度使用 rgba(var(--theme-accent-rgb), alpha)，文字优先使用 $color-main-text。
