# UI 重设计集中验收记录

日期：2026-11-05。当前必做实施已集中收尾；本记录区分实现、合成回归与真实浏览。未提交、未部署，未修改音乐 PlayerCore，未执行账号写操作。

## 本轮修正

- 榜单与歌手榜增加加载、错误、空态和重试；歌手榜隔离旧请求。
- 歌手详情分离必要资料和可选内容：资料失败可整页重试，局部失败保留已有内容并提示重试。
- 搜索九分类统一分页失败提示、同页重试和旧响应隔离；失败时暂停自动续载，成功后才提交页码。
- 用户主页结束失败骨架，区分完整失败与部分失败；重载先清理派生列表，避免歌单/收藏重复。
- 每日推荐校验路由与接口数据结构；无效路由数据回退接口。
- 浅色辅助文字加深至 #666，基础文字与基本表面的对比度组合通过检查。
- 保留既定效果：歌单/专辑封面 scale(1.3)、1.3 秒，不增加 hover 浮动/阴影；歌手效果不变；展开播放器保持精简入口。

## 尚无完整验收证据的项目

1. 浏览器真实断网/恢复：当前浏览器工具不提供离线切换；合成失败覆盖不能替代它。
2. 首帧全过程无闪烁：内联脚本逻辑已回归，当前工具不提供首帧录像。
3. 真实账号管理、关注/收藏/评论等写操作，以及登录后全部状态；本轮不执行这些写入。
4. 版权/网络降级的完整播放链路、真实渐弱响度及所有播放器浮层组合。
5. 图片叠字、渐变、遮罩和全部交互状态的逐像素对比度；基础 token 检查不等于完整无障碍认证。

可选主题色板仍按原决策排除当前必做范围。以上限制不应被改写为全站验收全部通过。
