# 剪辑执行手册｜抖音 45 秒竖屏

> 这份只管"怎么剪"，不管"说什么"。
> 配套：`douyin-video-01.md`（拍摄脚本 + 台词）、`douyin-video-01.srt`（字幕）、`safe-area-guide-1080x1920.png`（安全区参考图）

---

## 0. 开工前五分钟

**素材改名。** OBS 录出来是时间戳文件名，按镜头顺序改成 shot1 ~ shot7，剪的时候不用反复回放找。

| 文件 | 内容 | 目标时长 |
| --- | --- | --- |
| shot1 | 播放器展开 + 歌词 | 5 秒 |
| shot2 | 首页下滚 | 6 秒 |
| shot3 | 搜索到播放 | 7 秒 |
| shot4 | 歌词 + 换歌变色 | 8 秒 |
| shot5 | 私人 FM 3D | 8 秒 |
| shot6 | 刷新恢复 | 6 秒 |
| shot7 | 首页收尾 | 5 秒 |

**快速过一遍。** 每段看开头 3 秒，确认不是黑屏、鼠标可见、文字清晰。有问题的那段先去重录，别带着毛病往下走——剪到一半发现素材废了，比现在还多花一小时。

**素材放同一个文件夹**，别让剪映在桌面到处捞。

## 1. 建项目

1. 剪映专业版 → 开始创作
2. 导入 shot1–shot7
3. **先改比例**：预览窗口右下角比例按钮 → 选 9:16
4. 这时候先别把素材拖到时间线

比例一定要在拖素材之前设。顺序反了，剪映会重新计算所有片段的位置，你后面调的缩放全部作废。

---

## 2. 铺素材，把时间轴钉死 ⭐

**这一步是整条片子的地基。** 时间轴定死之后，字幕、配音、转场才能对齐；没定死就往下做，等于沙子上盖楼。

按顺序把 7 段拖进主轨道，逐段剪到目标时长，让分界点落在这几个秒数上：

| 段落 | 起点 | 终点 |
| --- | --- | --- |
| 1 | 0.0 | 5.0 |
| 2 | 5.0 | 11.0 |
| 3 | 11.0 | 18.0 |
| 4 | 18.0 | 26.0 |
| 5 | 26.0 | 34.0 |
| 6 | 34.0 | 40.0 |
| 7 | 40.0 | 45.0 |

**怎么剪准**：拖片段两端调长度，看时间线上的时长显示。差一两帧没关系，差半秒字幕就会整体错位。

**素材太长怎么办**：优先砍两端——开头鼠标还没准备好、结尾停顿太长，这些本来就是废帧。**不要靠加速硬压**，变速会让画面里的动作变快，鼠标移动看起来像抽帧。

**只有这两处值得加速**：

- 镜头 3（搜索流程）：1.15–1.2 倍速。动作多、等待多，压一压更紧凑
- 镜头 2（首页滚动）：滚得慢的话 1.1 倍速

加速之后**必须重新核对分界点**，变速会改变时长。

> **检查点**：七段剪完，时间线总长必须显示 `00:45`。差超过 0.3 秒就回头调。

---

## 3. 画面适配（16:9 → 9:16）

按镜头分两类处理。**同类镜头的缩放值必须完全一样**，否则切换时会像画面在呼吸。

### 满屏裁切 —— 镜头 1、4、5、6

选中片段 → 右侧「画面」→「基础」

- **缩放**：拖到画面上下顶满安全区（16:9 素材大约 200–230%，以实际顶满为准）
- **位置 Y**：0
- **位置 X**：往左挪 40–80，避开右侧按钮区
- 记下缩放数值，另外三段填同一个数

### 卡片式 —— 镜头 2、3、7

- **缩放**：调到宽度刚好铺满 1080（此时高度约 607）
- **位置 Y**：上移，画面顶端对齐安全区上沿
- 下方空出来的部分铺 `#0F0F23`

### 怎么让同类镜头的参数完全一致

剪映不支持选中多段后统一调画面参数——多选只能一起删、一起移，右侧「画面」面板只作用于最后点中的那一个。

**方法一（推荐）**：调好第一段，把「缩放 / 位置 X / 位置 Y」三个数字抄下来，依次点其他段直接输进去。尺寸相同的素材缩放值必然相同，这是换算不是估计。手动输入比拖拽准，也比拖拽快——拖到"差不多"的数值肉眼看不出，切换时就是轻轻一跳。

**方法二（时间轴还没定死时）**：调好第一段 → 复制粘贴三次 → 分别右键第 2、3、4 段 →「替换」→ 选对应素材。替换只换内容，保留全部参数。代价是入出点可能重置，要重新修剪。

**核对**：依次点选，看右侧缩放值是否**完全一样**。差 1% 都算没过。

### 铺参考图

`safe-area-guide-1080x1920.png` 拖到**最上层轨道**，拉满 45 秒，缩放铺满画布。所有镜头调完再删掉它。

透明没生效（显示成整块白）就把这层的「混合模式」改成**正片叠底**。

> **等比缩放不能解。** 16:9 拉成 9:16 会把整个界面压成胖子，宁可裁，不要拉。

### 安全区：只用到 85%，别贴边

抖音的安全区不是固定值，机型、版本、有没有挂载组件都会让它变。按"刚好贴边"去调，换台手机看就可能被压住一角。**永远往里收一圈。**

| 层级 | 内容 | 容错 |
| --- | --- | --- |
| 零容错 | 字幕 | 被压等于白做 |
| 尽量保 | 播放器控件、三张卡片、歌名 | 压掉边缘可接受 |
| 随便 | 网页导航栏、页脚、背景 | 本来就是裁掉的 |

保守区的具体数字（1080×1920）：

- 画面内容：y **160 → 1250**（参考图上的安全区下沿是 1310，再收 60px）
- 字幕：y **1300 → 1390**，居中
- 右侧：内容到 **x = 850** 为止（这一侧最确定：点赞/评论/收藏/分享竖排在那）
- 底部 y 1360 以下空着，不放任何重要内容

右边可以硬卡，因为按钮位置稳定；**底部最不可靠**，文案可能一行也可能三行，所以字幕宁可往上挪，不要往下贴。

**三个验证时机**

1. **剪的时候**：参考图不透明度调到 40%，盖着画面播一遍，用眼睛扫有没有越界
2. **导出后**：手机上全屏看一遍。电脑上正常的字幕，手机上经常刚好被压半行
3. **上传时**：抖音 App 发布页看一次，那儿底部就是文案输入框，能看到实际遮挡到哪

只有第三步是 100% 准的，前两步是估算。

> 别追求把画面正好卡进安全区。调位置花半小时，不如缩小一点居中放，多出来的边用 `#0F0F23` 填。观众看的是"这界面很精致"，不是"这界面正好占满屏幕"，留白比顶满高级。

## 4. 配音

每句单独生成，**不要整段粘一段文本生成**——AI 的停顿长度不可控，整段生成会跟镜头对不上。

1. 「文本」→ 新建文本，输入第一句台词
2. 选中文本 → 「朗读」→ 选音色（新闻播报类，语气平的那几个）→ 语速 1.05–1.1
3. 生成后把音频拖到对应镜头的区间里
4. 删掉这个临时文本（字幕稍后统一导入）
5. 重复七次

**检查**：每句配音不能超出本镜头时长。超了先降语速，还超就砍字——**砍字比拉长镜头好**，镜头时长一动，后面的字幕全要重排。

七句台词在 `douyin-video-01.md` 第 1 节的分镜表里。

---

## 5. 字幕

1. 「文本」→「导入字幕」→ 选 `douyin-video-01.srt`
2. 全选所有字幕 → 统一改样式：
   - 字号 **64–70**
   - 字体：思源黑体 / 阿里巴巴普惠体，挑粗一点的
   - 颜色：白
   - **不加描边、不加花字、不加打字机特效**
3. 整体位置往上挪到 y ≈ 1360，落在参考图的虚线框里
4. 关键词单独改色 `#8685EF`：每句只挑最关键的 2–4 个字，全改等于没改

> **检查**：有没有哪条超过 14 个字。超了就在标点处断成两条，不要缩字号。

---

## 6. 音乐和节奏

**BGM**

- 「音频」→「音乐素材」→ 搜 lo-fi / 轻电子，90–110 BPM
- 裁到 45 秒，末尾加 0.5 秒淡出
- 音量降到 **20% 左右（约 -18dB）**，别盖住配音

**推近（只给静止画面用）**

不是每段都要推。**本身就在动的镜头再推会让人晕**，只推构图静止的：

| 镜头 | 状态 | 处理 |
| --- | --- | --- |
| 1 歌词 | 歌词在滚，构图静止 | 推近 4% |
| 2 首页滚动 | 本身在滚 | 不推 |
| 3 搜索 | 画面一直在变 | 不推 |
| 4 歌词 + 变色 | 算半个动态 | 轻推 2% 或不动 |
| 5 私人 FM 3D | 卡片自己在转 | 绝对不推 |
| 6 刷新 | 有白屏跳动 | 不推 |
| 7 收尾定格 | 完全静止 | 拉远 3% |

操作：播放头停在**片段第一帧** → 「画面」→「基础」→ 点缩放右边的**菱形图标**落第一个关键帧 → 播放头拖到**最后一帧** → 改缩放数值，第二个帧自动生成。只打一个帧不会动。

**数值要在当前缩放值上乘，不是从 100% 起推**。满屏裁切段已经调到 220% 了，正确写法是 `220 × 1.04 ≈ 229`，不是「推到 104」——后者会先缩回去再放大，画面会啪地跳一下。记「乘 1.03–1.05」，别记「加 4」。

三个坑：幅度别超 8%；缩放以画面中心为基准，边缘内容会被裁掉，播到最后一帧看一眼；关键帧默认线性，版本支持的话设「缓入缓出」更自然。

**转场**

只用一处——镜头 1 → 2，加 0.2 秒叠化。其余全部硬切。转场花哨会显得廉价。

## 7. 导出

| 项 | 值 |
| --- | --- |
| 分辨率 | 1080P |
| 帧率 | **60** |
| 码率 | 更高 |
| 格式 | MP4 |

**帧率默认是 30，必须手动改成 60。** 你录的是 60fps，项目按 30 处理的话，镜头 5 的卡片旋转和镜头 2 的滚动就等于白录了。

导出后一定在手机上全屏看一遍，电脑上看没问题不代表手机上看没问题。

---

## 8. 导出前自检

- [ ] 总长 45 秒，七个分界点对得上
- [ ] 同类镜头的缩放值一致，切换时没有忽大忽小
- [ ] 字幕全部在虚线框内，没有被底部文案压
- [ ] 每句配音都没超出本镜头
- [ ] 画面没有变形（等比缩放没被解开）
- [ ] 导出帧率是 60
- [ ] 最后一帧停在"地址在主页简介"

## 9. 卡住了怎么办

**某个镜头找不到合适构图**
说明录的时候取景太宽。退一步改成卡片式，别硬裁。卡片式看起来"这是给你看一个网页"，反而更自然。

**字幕整体对不上**
八成是时间轴没钉死就导了字幕。回第 2 步重剪，SRT 不用改。

**配音念错字**
改文本重新生成，别用别的软件补——音色不统一比念错更难听。

**画面切换时有一跳**
检查两段的缩放值是不是差了几十。多半是当时没记数值，凭感觉拖的。
