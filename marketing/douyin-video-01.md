# 抖音视频 01｜好看好用（45 秒）

> 一句话：**别人刷到这个视频，第一反应应该是"这也太好看了"，第二反应才是"这个能用"。**
> 所以全程不谈技术、不谈框架、不谈架构，只谈"看起来怎样"和"用起来顺不顺"。

---

## 0. 成片参数

| 项 | 值 |
| --- | --- |
| 时长 | 45 秒（素材不足可压到 38 秒，删镜头 3 的后半段） |
| 画布 | 1080 × 1920 竖屏 |
| 画面处理 | 网页**放大 1.5–2.2 倍后取局部**，铺到 1080 全宽、下沿压到 y≈1350。首页/搜索这类要看整体布局的镜头例外，缩成 1080×607 卡片式居中 |
| 安全区 | 右侧 200px、底部 500px 会被平台按钮和文案压住。关键信息只放**左边 880px 内、y 150–1350** 之间 |
| 帧率 | 60fps（网页滚动和 3D 视差必须 60，30 会糊） |
| 声音 | 抖音曲库 BGM，**界面里的歌不要出声** |
| 形式 | 纯录屏 + 大字幕（不需要露脸，工具类内容这样完全能打） |

**为什么开场不说年份**

"2022 年的项目，今年重做了"是背景，不是钩子——刷到的人不关心你的项目史，只关心这跟他有什么关系。而这个画面本身就有反差：精致到这个程度，观众会默认它是原生客户端。

所以第一句给"网页也能做成这样"，用认知落差把人留下；第 5 秒才交代年份和 AI。**背景信息要在对方已经想听的时候说，说早了就是自我陈述。**

顺带把"只支持电脑"也并进来，第 5–11 秒一次说完，别拖到结尾才让人发现白跑一趟。

**可选加料：2022 旧版对比**

如果你还留着 2022 年的旧版截图，开头换成这个，效果强一大截：

| 时间 | 画面 | 字幕 | 口播 |
| --- | --- | --- | --- |
| 00:00–00:02 | 2022 年的旧版首页截图，可以稍微调灰 | 2022 年，长这样 | 这是我 2022 年做的。 |
| 00:02–00:06 | 硬切到现在的播放器展开态 | 今年重做了一遍 | 今年用 AI 把界面重做了一遍。 |

新旧反差比任何功能演示都抓人，因为它直接证明"好看"这件事。没有旧截图就别硬凑，现有开场也够用。加了这个开头，成片总长变 46 秒，镜头 2 起各顺延一秒。

**配音说明（AI 配音专用）**

- 音色别选「磁性男声」「温柔女声」这类刻意煽情的，选**普通话标准、语气平**的（新闻播报类），语速调到 1.05–1.1 倍
- AI 在句号处停 0.4 秒左右，正好当节奏用；所以稿子一律用**短句 + 句号**，不要长句堆逗号，否则会读得一顿一顿
- 避免中英混排：`App` 会被念成字母，「私人 FM」念字母还算自然，可以保留
- 年份先按 `2022 年` 生成，试听一遍。如果 AI 念成"两千零二十二"，手动改成"二零二二年"

**文案原则：怎么才算"不装"**

具体事实 > 形容词。「一个字一个字亮起来」比「极致丝滑」有力，「刷新一下还在」比「体验拉满」可信。全程不出现"惊艳""丝滑""绝了""拿捏"，也不写"我熬了好几年"这种苦情叙事——照实说"2022 年搭的框架，今年用 AI 重做"，把分量交给画面。

**主动说 AI 是加分项**：现在"用 AI 改老项目"是话题点，坦诚比遮掩更容易激起评论——有人会说"AI 做的有什么了不起"，也有人会说"改得真好"，两种都在帮你涨互动。别一句都不提，容易被人扒出来反而难看。

结尾必须留一句求反馈的话。这既是你要的"请大家提建议"，也是抖音评论区互动率最高的写法：**求建议比求点赞有用得多**。

**节奏原则**：镜头 1 先出画面、第 2 秒才开口，不要一上来就说话。镜头 3 和 6 要一气呵成、中途不剪，这两段是"好用"的全部说服力。

## 2. 录屏操作指令（照着点就行）

### 录屏软件：OBS Studio

免费、无时长限制、码率可调到接近无损，而且能只录 Chrome 窗口、不录桌面。**默认设置录出来会糊，必须改下面三处。**

**设置 → 输出**（先把顶上的「输出模式」切成「高级」）

| 项 | 值 |
| --- | --- |
| 编码器 | 有独显选 `NVENC H.264` / `AMD HW H.264` / `QuickSync H.264`；没有就选 `x264` |
| 比特率控制 | **恒定 QP**（就是 CQP，但 OBS 中文界面里不写 CQP，别去找这三个字母），下面的数值填 **18**（越小越清晰，18 基本无损，20 也够用） |
| 路径 | 别放桌面。CQP 18 录 1440p60 一分钟 500MB–1GB，换到 `Videos/acmusic` 之类，录完一次清掉 |
| 预设 | **Quality**（质量） |
| 配置文件 | high |
| 录像格式 | **mkv**（OBS 中途崩了文件不会坏），录完用「文件 → 重新封装录像」转成 mp4 |

改成恒定 QP 之后，「多次编码模式」和「B 帧」会变灰——正常，那两项只在 CBR/VBR 下生效。

**如果找不到「恒定 QP」**：退回 CBR，但比特率必须提到 **40000 Kbps**，关键帧间隔填 2。1440p60 用 10000 Kbps 是 1080p30 的量级，滚动和 3D 视差一上来就是块状噪点，再放大 2.2 倍更救不回来。

**设置 → 视频**

| 项 | 值 |
| --- | --- |
| 基础（画布）分辨率 | 你的屏幕分辨率 |
| 输出（缩放）分辨率 | **跟基础一致，绝对不要缩放**（这一项是糊掉的头号原因） |
| 常用 FPS | **60** |

**来源**

首选 **「显示器采集」**。添加 → 显示器采集 → 采集方式留 `自动` → 勾「捕获光标」。
因为你会 F11 全屏，录整个屏幕就等于录浏览器，还能绕开窗口采集的一大堆毛病（找不到窗口、黑屏、高 DPI 尺寸错位）。

**必须配合热键**：设置 → 热键，给开始/停止录制各设一个键（F9/F10）。录制期间用热键，**别切到 OBS 窗口去点按钮**，否则 OBS 界面会被录进画面。

如果一定要用窗口采集：

- 先把浏览器点到前台，再回 OBS 打开下拉——**这个列表是打开对话框时快照的，不会实时刷新**
- 浏览器和 OBS 必须同一权限级别（都以管理员身份跑，或都普通权限），权限不一致会直接过滤掉窗口
- 关掉浏览器的「启动加速 / 后台继续运行」，结束所有残留进程再重开
- 采集方法选 **Windows 10 (1903 and up)**，勾上「捕获光标」→ 右键源 → 变换 → 适配屏幕

**三个必踩的坑**

- **录出来一片黑** → 采集方法改成 `BitBlt`；还不行就先关掉 Chrome 的硬件加速再录
- **录出来糊** → 八成是输出分辨率被缩放成了 1280×720，或者 CQ 值填到了 25 以上
- **一个文件几百 MB** → 正常。1080p60 一分钟约 200–400MB，这条片子的素材加起来轻松 2–3GB，录之前清一下磁盘

**懒得配就用 Win + G**：Windows 自带，`Win + Alt + R` 直接录当前窗口，零安装。设置里把画质调到 1080p60。缺点是码率不可控、有时识别不到浏览器窗口，画质比 OBS 差一档——赶时间能用，但这条片子建议还是 OBS，因为你要放大裁切，素材余量越大越好。

### 开机前

- F11 全屏 → 地址栏和书签栏一起消失（画面里出现 URL 有被判站外引流的风险）
- Ctrl+Shift+B 隐藏书签栏，关掉所有其他标签页
- 浏览器缩放调到 **125%–150%**（UI 在手机屏上才看得清，也给后期放大留余量）
- 关微信/QQ 通知，锁桌面
- 用 OBS「显示器采集」，F11 全屏后等价于录浏览器（设置见上一节）
- 鼠标开点击高亮（PowerToys 的鼠标荧光笔），否则观众看不出你点了哪

### 每个镜头的操作要点

**镜头 1｜播放器展开**
进入任意歌曲 → 点底部条展开 → 等歌词滚到当前行再开始录。录 8 秒，后期取 4 秒。
选歌标准写在下面「素材准备」里，这条片子成败一半在这个镜头。

**镜头 2｜首页下滚**
从顶部开始，匀速滚，大约 1 秒滚 100px。中途鼠标划过两张卡片停 0.3 秒，让悬停浮起效果出来。滚太快会糊，滚太慢会闷。

**镜头 3｜搜索到播放（一镜到底）**
点搜索框 → 输入歌手名 → **停 0.5 秒**让联想词弹出来（这一停很关键，观众需要时间看懂）→ 回车 → 列表出来后停 0.3 秒 → 点第一首 → 底部条滑出后停 1 秒。
手别抖，别来回找光标。录三条取最稳的一条。

**镜头 4｜歌词 + 换歌变色**
先不切歌，让歌词在画面里点亮 2–3 个字（特写感），再点下一首。
**这两首歌的封面主色必须差异很大**——一首冷色（深蓝）、一首暖色（橙红），变色才有冲击。提前试听确认，别现场随机。

**镜头 5｜私人 FM 3D**
鼠标在卡片区域**缓慢、连续**地左右移动，幅度不要大（半个卡片宽度足够）。移太快录出来是抖动，看起来像卡帧。
注意这是鼠标跟随的视差，用触控板会有惯性，建议用鼠标录。

**镜头 6｜刷新恢复**
F5 之前先暂停 1 秒（让观众看清当前进度），刷新后等画面完全恢复再停 2 秒。
后期把白屏那 1 秒剪掉一半，只留 0.3 秒——留满了观众会以为卡了。

## 3. 素材准备清单（拍之前必须做，最容易被忽略）

**选歌，这是这条片子最重要的准备工作：**

| 用途 | 要求 |
| --- | --- |
| 镜头 1 / 4 的主歌 | 封面是**深蓝或墨绿**这种浓度高的暗色（取色后背景才有质感，白色封面会取成灰） |
| 镜头 4 的对照歌 | 封面是**暖橙或暗红**，且跟主歌色相差越大越好 |
| 全部 | 歌词要密（中文歌、有逐字时间轴），避开纯音乐（会显示"暂无歌词"） |
| 全部 | 避开需要会员/会触发音源降级的歌，否则现场可能搜不到 url |

**其他：**

- 用一个干净的账号（或游客态），别把自己的头像、昵称、"我喜欢的音乐"里那些私人歌单名露出来
- 提前把音量关掉（系统音量静音），避免录进真实歌曲声——版权识别会把流量判给那首歌
- 录之前完整跑一遍"点歌→出声→换歌→刷新恢复"，确认音源链路通（你的降级链在某些网络下会走代理，容易卡）

## 4. 剪辑规范

**版式（按抖音安全区排）**

```
┌───────────────────┐  1080 × 1920
│ ░░░ 顶栏遮挡 ░░░░ │  y 0–150     推荐/关注 tab
│  ┌──────────────┐ │
│  │              │ │  网页画面
│  │   网页画面   │ │  x 0–880 · y 150–1350
│  │（放大取局部）│ │  右侧 200px 会被点赞按钮压
│  │              │ │
│  └──────────────┘ │
│     大 字 幕       │  y 1400–1500  字号 64–72
│ ░░░ 文案遮挡 ░░░░ │  y 1500–1920  账号名、音乐名
└───────────────────┘
```

为什么必须放大：可用画面区是 1080×1350，而 16:9 素材缩到 1080 宽只有 607 高。要填满 1350 的高度得放大约 **2.2 倍**，放大后横向只剩原网页 **45%** 的宽度。所以「取局部」不是风格选择，是算术结果——好在播放器左侧那块、私人 FM 的三张卡，本来就在网页里占 40–50%，天生适合。

**例外**：镜头 2（首页）、镜头 3（搜索结果）需要展示整页布局，观众才看得出「这是个网站」。这两个镜头把网页缩成 1080×607 居中放，上下用 `#0F0F23` 填。卡片式和满屏式混用不违和，反而有节奏：满屏是「好看」，卡片是「这是网页」。

**剪映操作（四步）**

1. **先设比例再导素材**。预览窗口右下角的比例按钮选 9:16。顺序反了，剪映会重算所有片段位置，前面调的全废。
2. **满屏裁切**（镜头 1、4、5、6）：选中片段 → 右侧「画面」→「基础」→ 拖「缩放」到画面上下顶满安全区。16:9 填满约 1160 的高度需要 **200–230%**，别记数字，拖到刚好顶满再记下当前值，同版式镜头统一填这个数。位置 Y 归 0，X 往左挪避开右侧按钮区。
3. **卡片式**（镜头 2、3、7）：缩放调到宽度刚好铺满 1080（高度约 607），位置 Y 上移，下面留黑。
4. **铺参考图**：`safe-area-guide-1080x1920.png` 拖到时间线最上层，拉满全长、缩放铺满画布，调完删除。透明没生效就把混合模式改「正片叠底」。

**等比缩放不能解**。16:9 拉成 9:16 会把整个界面压成胖子，宁可裁不要拉。

**裁切后光标可能跑出画面**：满屏裁切左右各切掉约 660px，如果当时在页面右侧点击，裁完看不见光标。用剪映贴纸补个圆点指过去，不用重录。

- 上下填充色：`#0F0F23`（正好是项目的兜底色，接得住画面，不抢戏）
- 字幕：白字，关键词用主色 `#8685EF` 高亮；不要描边、不要花字、不要打字机特效
- 每个镜头加 3–5% 的缓慢推近（Ken Burns），避免画面"死"在那里
- 转场：以硬切为主，只在镜头 1→2 用 0.2 秒叠化。转场花哨会廉价
- 整体 1.15–1.25 倍速，把所有加载白屏和鼠标犹豫的段落剪掉
- BGM：抖音曲库搜 lo-fi / 轻电子，90–110 BPM，音量压到 -18dB 左右，别盖过节奏
- 导出：**1080P / 60fps / 码率「更高」/ MP4**。帧率最容易漏——剪映默认 30，项目按 30 处理的话，60fps 的素材等于白录，3D 视差和滚动会重新变顿

## 6. 发布包

**标题（三选一，推荐第一个）**

1. 我写了个网页播放器，换首歌整个界面跟着变色
2. 2022 年搭的框架，今年用 AI 重做了界面
3. 刷新一下，进度还在

标题里放一个**具体到反常的细节**，比放形容词有效十倍。"换首歌整个界面跟着变色"就是那种让人想点开确认一下的描述——它不评价自己好看，只是陈述一个事实，反而更可信。

**话题**

`#独立开发 #前端 #程序员 #网页设计 #Vue #个人项目`

不要加 `#网易云音乐`——等于主动把视频推进版权审核池。

**封面**

用镜头 4 那一帧（播放器展开 + 歌词点亮 + 背景已变色），压四个大字：**浏览器听歌**。
不要用官方 logo 做封面，商标风险。

**主页简介（三行，地址放第一行）**

```
music.archai.space
目前只支持电脑浏览器，手机端还没做
```
