# 提示词包

> 用途：把这条片子的上下文和需求固化成可以直接粘给 AI 的文本。
> 不需要每次都重新解释项目背景——**P1 先粘，后面挑一段粘**，任何 AI 都能接着干。

---

## 用途速查

| 你想干什么 | 粘哪段 |
| --- | --- |
| 让任何 AI 理解这个项目 | **P1** |
| 重新设计封面 / 想封面文案 | P1 + **P2** |
| 换一种风格重写台词 | P1 + **P3** |
| 发之前挑毛病（限流、误解。转化） | P1 + **P4** |
| 把整套方法套到下一个项目 | P1 + **P5** |

---

## P1 · 项目背景

```
我在做一个个人项目 ACMUSIC，是一个网页版的音乐播放器，Vue 2 写的，2022 年搭的框架，2026 年用 AI 重做了界面。只有桌面端，手机上打开会提示换电脑。

它的几个特点：
- 打开浏览器就能用，不用安装任何东西
- 歌词是逐字点亮的，不是整行变色
- 换歌的时候，整个界面背景会跟着新封面的主色重新生成
- 私人 FM 是三张 3D 卡片，鼠标移动时卡片会跟着倾斜，带镜面倒影
- 刷新页面后能恢复上次播放的歌曲和播放进度

我要在抖音发一条 45 秒的介绍视频，竖屏，展示它的界面和交互。我不出镜，靠录屏 + 字幕 + AI 配音。
目标观众是刷抖音的年轻人和独立开发者，目的是让人愿意去试用。

我说话不喜欢太"装"：不要形容词堆砌，不要自夸，不要把普通功能说得惊天动地。具体事实比形容词有力。
```

## P2 · 封面设计

```
你是一个短视频封面设计师。请为一条抖音视频设计封面，给出可以直接执行的排版参数。

素材：我有一段播放器界面截图。深色背景，左边是专辑封面、歌名、进度条和控制按钮，右边是正在逐字点亮的歌词。
视频内容：45 秒，展示一个网页版音乐播放器的界面和交互，卖点是"好看"和"顺手"。
目标观众：手机竖屏刷抖音的年轻人和独立开发者。

背景约束（很重要）：
- 画布 1080×1920，但抖音主页作品列表会按 3:4 裁成 1080×1440，上下各切掉 240px
- 所有关键信息必须落在 y 240–1680 之间

请输出：
1. 三组主标题，每组不超过 8 个字，必须是一个具体事实或反差，不要形容词堆砌
2. 每组配一句副标题（可选，不超过 12 字）
3. 推荐排版：主标题字号、y 坐标、颜色、要不要加投影
4. 说明第一组为什么比另外两组好

不要：不要用"极致""丝滑""绝了""拿捏"；不要承诺视频里没有的东西；不要建议加描边、发光、花字——画面本身已经够干净，加特效只会显廉价。
```

## P3 · 换风格重写台词

```
你是一个抖音短视频文案。请把下面这条 45 秒视频的台词重写一版，风格是【在这里填你要的风格，比如：更口语、更冷静、更有反差】。

现有台词：
镜头1 00:00–00:05｜网页也能做成这样｜网页也能做成这样。打开就能用。
镜头2 00:05–00:11｜2022 年搭的框架，今年重做｜2022 年搭的框架，今年用 AI 重做了一遍。只支持电脑。
镜头3 00:11–00:18｜搜歌手，搜歌，搜歌单｜搜歌手，搜歌名，搜歌单。点一下就开始放。
镜头4 00:18–00:26｜歌词一个字一个字亮起来｜歌词是一个字一个字亮起来的。换一首歌，整个界面会跟着换颜色。
镜头5 00:26–00:34｜鼠标一动，卡片跟着转｜这是私人 FM。鼠标动一下，卡片会跟着转。
镜头6 00:34–00:40｜刷新一下，进度还在｜刷新一下，还是刚才那个进度。
镜头7 00:40–00:45｜地址在主页简介，不好用也说｜想试的看我主页简介。哪里不好用，也欢迎告诉我。

硬约束：
- 还是 7 句，对应 7 个镜头，每句不超过 15 个字
- 必须能直接口播：不能有生僻词，不能中英混排（"App"要写成"软件"），数字写汉字
- 每句用句号结尾——这是给 AI 配音用的，句号处停顿 0.4 秒，正好当节奏
- 不出现"极致""丝滑""绝了""拿捏"
- 最后一句必须包含"求建议"的意思
- 不要写"我熬了好几年"这类苦情叙事

输出：一个表格，四列——镜头号、时间、字幕版（更短）、口播版（稍长）。
表格下面另起一段，说明你改了什么、为什么。
```

## P4 · 发之前挑毛病

```
你是一个严格的抖音内容审核员，同时也是短视频运营。请检查下面这条视频，找出会被限流、会被观众误解、或者会导致转化流失的地方。

项目背景：（把 P1 粘在这里）

台词与字幕：（把 srt 内容粘在这里）

封面文案：（填封面上的字）

请按严重程度从高到低排序，每条给出：问题是什么、为什么是问题、具体怎么改。

重点检查这几项：
1. 有没有平台敏感表达（第三方客户端、免费听歌、破解、VIP、外链网址）
2. 有没有承诺了做不到的事
3. 前 3 秒够不够抓人，观众最可能在第几秒划走
4. "只支持电脑"这个限制，说的时间点合不合适
5. 结尾的引导是不是最短路径

不要泛泛而谈"可以更吸引人"，每条都给可以直接替换的句子。
```

## P5 · 套用到下一个项目

```
帮我把下面这套短视频制作方法，套用到我的新项目上。

方法概要：
1. 45 秒、7 个镜头，时间分配按"钩子 5s / 定位 6s / 核心功能 7s / 视觉高潮 8s / 视觉高潮 8s / 细节反转 6s / 收尾 5s"
2. 第 1 句必须是认知反差（画面精致到不像），不要讲项目历史
3. 背景信息（做了多久、用了什么工具）放在第 2 句，因为那时观众已经想听了
4. 限制条件（比如只支持某个平台）要在前 10 秒说，不要放到结尾
5. 台词风格：具体事实 > 形容词，不写苦情叙事，结尾求建议而不是求点赞

新项目：
【项目名】
【一句话说清它是什么】
【三个最能打动人的特点，要具体到能被验证】
【它的限制或缺点】
【目标观众】

请输出：7 个镜头的时间表、每个镜头该展示什么、每句台词（字幕版 + 口播版），以及说明你为什么这样排。
```
